## Capabilities it proposed

### "Add a real-time assistant that watches mac-vision's planned UI actions and intercepts any fallback mouse clicks to avoid accidental focus stealing, confirming risky steps before execution and allowing user intervention."
- **useful because:** Fallback mouse clicks by mac-vision on background windows risk stealing the owner's focus unexpectedly and disrupting workflow. A real-time governance layer watching these events would provide safety, transparency, and user trust.
- **path:** mac-vision → mac-planner
- **model tier:** gpt-5.6-luna
- **latency:** milliseconds to sub-second reaction time
- **cost:** Moderate, requiring always-on monitoring and some event logging and dialog interaction costs
- **security:** This layer must not be bypassable without explicit owner approval. It must respect owner privacy and only intervene on UI events generated by mac-vision, not normal user input.
- **missing:** Realtime UI event monitoring capability in mac-vision loop to catch fallback mouse clicks; User interaction surface for confirmation and override

### "Create a comprehensive multi-agent goal and task coordination system that integrates owner-stated tasks, calendar events, agent-generated findings, and cross-device states, providing ranked, actionable goals that all agents including mac-vision can query and update."
- **useful because:** Currently there is no unified source of truth for 'what the owner wants done' that combines high-level owner intent, task priority, due dates, dependencies, and agent context. This would enable smarter prioritization, progress tracking, and collaboration among agents across devices.
- **path:** mac-vision → mac-planner → relay-realtime → browser-extension
- **model tier:** gpt-5.6-luna
- **latency:** seconds for updates, fast query responses
- **cost:** Moderate to high, involving database coordination and multi-surface API design
- **security:** Must tightly control task visibility and updates for owner privacy. Access control for agent roles must prevent data leaks or accidental overwrites.
- **missing:** A robust API and data store for goal/task coordination with multi-agent locking and eventing; Cross-surface synchronization mechanisms; Policy and UI for owner task management and priority setting

### "Enable the pendant button to mark moments in the mac-vision run history with custom metadata payloads to create rich bookmarks and context tags, extending existing timestamping to structured annotations."

- **path:** mac-vision → pendant
- **model tier:** gpt-4.1-mini
- **latency:** milliseconds to seconds for marker storage
- **cost:** Low, using the already granted pendant button and its embedded key-value store
- **security:** Must ensure data integrity and that only authorized metadata is recorded with clear owner intention.
- **missing:** API from mac-vision to pendant for annotating moment markers with structured payloads; User UI to specify or confirm payload content when pressed
