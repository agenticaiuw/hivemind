## Capabilities it proposed

### "“Pin this page for me — keep the important details, remind me what I need to do, and let me pick it up from the pendant later.”"
- **useful because:** Authenticated pages disappear when a tab closes, sessions expire, or the owner leaves the Mac. This turns a private Safari page into a bounded, cited handoff: the owner can hear the key facts on the pendant, review the source on the Mac, and resume later without granting the relay a reusable login session. It is materially different from a one-shot page read or a draft form fill because it preserves continuity across surfaces while keeping the source evidence private and expiring.
- **path:** browser-extension: capture the active authenticated tab’s URL/title, selected semantic passages, and a small screenshot or DOM anchors → relay: encrypt and retain the evidence capsule for a short TTL, expose citation and expiry metadata, and route a follow-up question to the right surface → mac-planner: create a local Markdown/Notes artifact and optionally a reminder containing only the extracted task and a link back to Safari → pendant: speak a 20–30 second summary, announce expiry, and accept follow-up questions or “open it on the Mac” → dashboard: show pinned capsules, source age, sensitivity, and delete-now control
- **model tier:** Background/cheap model for extraction, deduplication, and task-field normalization; realtime only for the pendant’s follow-up conversation and concise readout.
- **latency:** Initial capture 3–8 seconds while the page is open; pendant readout under 2 seconds after the capsule is available; follow-up answers 2–5 seconds. No background polling unless the owner explicitly asks to watch the page.
- **cost:** Roughly $0.01–$0.05 per pin, dominated by page-text/screenshot extraction and one summarization call; storage is negligible if capsules expire in 24–72 hours. Realtime follow-ups cost the normal voice turn only.
- **security:** Private page text must not be sent to public web search or the relay model without an explicit per-pin privacy choice. Default to local Mac extraction where possible, encrypt in transit and at rest, redact payment/authentication tokens, never store cookies, and expire/delete the capsule and its Mac artifact on request. A reminder containing sensitive text should require the owner to choose a local-only destination. Opening the source tab is reversible; any submit/send action remains outside this capability.
- **missing:** A first-class browser evidence-capsule schema with encrypted payload, TTL, sensitivity label, source URL/tabId, DOM anchors, and citation hashes; A browser action to capture semantically relevant regions rather than only whole-page text; Relay storage and retrieval endpoints with owner-scoped access and explicit delete/expiry; Mac artifact/reminder integration that stores a local pointer and redacted summary; Pendant intent routing for pin, recall, summarize, and open-source commands; A privacy selector (local-only, encrypted relay for 24h, or longer retention) and a reliable deletion receipt

### "“Point out exactly where that is on the page.”"
- **useful because:** While the owner is looking at a logged-in Safari page, they can ask the pendant about an unfamiliar clause, number, or option and get both an answer in their ear and a visual pointer on the Mac. The browser supplies private context, the model grounds the answer to a precise passage, and the Mac scrolls/highlights it; this is a coordinated live explanation rather than a page summary, watch, form fill, or saved brief.
- **path:** pendant: capture the spoken question and read back a concise answer → browser-extension: inspect the active authenticated tab and return matching text plus stable DOM coordinates → relay: resolve the question against the cited page region and return a confidence-scored answer → mac-vision/mac-planner: scroll to the matching region and apply a temporary highlight or overlay, then remove it after a timeout → dashboard: show the quoted passage, confidence, and a one-tap clear-highlight control
- **model tier:** Realtime for the short spoken question and answer; a cheaper background model can rerank page regions when the match is ambiguous. No public search or long-lived storage is needed.
- **latency:** 1–3 seconds for ordinary pages; up to 5 seconds for a long or virtualized page. The temporary highlight should appear within 1 second after the browser returns the locator.
- **cost:** About $0.005–$0.03 per question, dominated by extracting and ranking page regions; no meaningful storage cost.
- **security:** Page text is private and must remain within the owner-scoped browser/relay path; do not send it to public search. Return only the smallest relevant excerpt, redact secrets and hidden fields, and make the highlight ephemeral. If confidence is low, say so and show the candidate passages rather than inventing an answer.
- **missing:** A browser query action that returns semantic text regions with robust locators for dynamic pages; A cross-surface request correlation ID linking pendant speech, browser evidence, and Mac highlight; A Mac overlay/scroll action that targets a browser tab without stealing keyboard focus; A confidence threshold and ambiguity response format; A temporary-highlight cleanup mechanism and user-visible citation receipt


## Changes it proposed to its own stack

### `browser-harness` — Implement an expiring, provenance-preserving Evidence Capsule protocol. A browser capture command should package normalized text spans, optional low-resolution screenshot regions, URL/title/tabId, capture time, DOM locator or quote anchors, and per-span hashes; the relay stores only an encrypted capsule keyed to an owner/job ID with a hard TTL and deletion receipt. The Mac receives a redacted local artifact plus a capsule pointer, while follow-up retrieval verifies the source hash and clearly reports when the page has changed or the capsule expired. Add idempotent capture/delete and never include cookies, headers, or hidden form values.
- **owner gets:** The owner can close Safari and still trust what the pendant says later, with a way to inspect exactly where each fact came from and to delete it. It prevents stale private-page summaries from masquerading as current truth and avoids forcing the owner to keep sensitive tabs open.
- effort: Medium-high: shared schema and crypto/storage work in relay, browser extraction and anchor generation, Mac artifact integration, deletion/expiry tests, and pendant intent wiring.  ·  risk: A DOM anchor may become invalid or a screenshot may contain more sensitive content than intended; the capsule must mark evidence stale rather than silently re-extracting. Recovery is to show the quoted text and source URL, let the owner delete the capsule, and require a fresh browser capture for current facts. Key loss must make expired capsules unrecoverable by design.
- cost: One cheap extraction/summarization call per capture (about $0.01–$0.05); short-lived encrypted object storage is pennies per month at personal scale. Screenshot OCR/vision is the dominant cost when requested.  ·  latency: About 3–8 seconds for capture and packaging; retrieval is sub-second from relay, with a 2–5 second model call only for a follow-up question.
- security: Improves security by isolating cookies and using owner-scoped encryption, TTL, redaction, and deletion receipts; still requires a clear local-only default and audit trail for every relay read.
- depends on: Durable browser job runner and result stream (chg-16bc5dee); Provenance-aware browser workbench (chg-e14fff33); A relay owner-scoped encrypted object store and capsule retrieval route; Mac local artifact/reminder action and pendant intent routing

### `browser-harness` — Add a live page-pointer protocol for conversational browser questions. The extension returns a minimal set of semantic regions for the active page, each with quote text, bounding rectangle, frame/tab identity, and a resilient locator (text plus nearby heading, not a brittle CSS selector). The Mac bridge consumes a signed pointer token to scroll and draw a temporary non-input-blocking highlight; the token expires after 60 seconds. If the DOM changes, the bridge must refuse to highlight and request a fresh capture instead of pointing at the wrong content.
- **owner gets:** The owner can ask about a private page naturally and immediately see the exact evidence being discussed, reducing missed details and giving them confidence that the answer is grounded in the page in front of them.
- effort: Medium: extension extraction and locator matching, relay correlation, Mac overlay/scroll integration, and dynamic-page tests across iframes and virtualized lists.  ·  risk: A stale or ambiguous locator could highlight the wrong text or reveal adjacent sensitive content. Limit highlights to the quoted region, use short expiry, require confidence thresholds, and fail closed with candidate excerpts when matching is uncertain.
- cost: Negligible storage; roughly one small extraction/ranking model call per question, around $0.005–$0.03. Overlay rendering is local.  ·  latency: Adds about 1–3 seconds for extraction and answer generation; highlighting itself should be near-instant once the pointer arrives.
- security: No cookies or credentials leave Safari. The signed, expiring pointer prevents replay and restricts the Mac action to the originating tab and quoted region.
- depends on: A working browser command enqueue path; Cross-surface request correlation IDs; Mac browser overlay/scroll primitive; Semantic region extraction for authenticated pages
